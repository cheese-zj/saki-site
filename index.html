The idea

Keep the interaction.
Adapt the motion.

A human demonstrates an interaction in one scene. A mobile robot must realise it with a different body, new object locations and changing viewpoints. SAKI separates what the interaction requires from the motion needed to carry it out.

Reusable skills preserve contact, orientation and terminal relations. Scene estimates ground them in the current workspace; coordinated base, arm and gripper motion connects them into longer tasks.

From a video to a connected task.

Inside SAKI
01 / Prepare

Learn the
interaction.

Recover object motion from a human video and prepare a reusable skill. Retain how the object is held, where contact persists and how the action ends.

Interaction requirements stay with the skill; the transfer path can change.

02 / Ground

Reuse it in
a new scene.

Bind object roles to current scene estimates. Whole-body kinematic imitation generates coordinated robot motion to realise the interaction.

Accepted visual updates revise remaining targets while preserving motion already committed to the robot.

03 / Assemble

Separate skills.
One longer task.

Select, order and bind independently prepared skills to objects in a shared workspace. Dispose of a can, place tape and wipe a surface in a connected mobile sequence.

Retained scene estimates and the preceding robot configuration initialise the next skill.
